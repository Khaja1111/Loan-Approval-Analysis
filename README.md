# Loan-Approval-Analysis
EDA for Machine Learning project that predicts loan approval status using applicant financial and credit data through data preprocessing, exploratory analysis, and predictive modeling with Python and Scikit-learn.

Objective
Analyze financial information to understand factors associated with loan approval.

Tasks Performed
Data inspection
Missing value detection
Duplicate checking
Outlier detection
Data visualization
Correlation analysis
Feature engineering
Dataset cleaning

Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
